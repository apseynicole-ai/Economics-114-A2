# ECO114 A3 Study Hub

This repository is being organised into a split ECO114 A3 study system for Economics 114.

## Project Purpose

The goal is to build an exam-focused A3 preparation system that combines source auditing, graph/model revision, calculations, application practice, past-paper mapping, and final exam strategy.

## Current A3 Output Split

The A3 HTML output is split into four local files:

1. `exports/html/eco114_a3_index.html` - completed A3 control centre for hub navigation, study routes, 14-day planning and progress tracking
2. `exports/html/eco114_a3_foundations_units_1_to_5_v2_unit_tabs.html` - recommended Foundations v2 unit-first hub for Units 1 to 5 with each unit's theory, graphs/models, logic cards, traps, templates and practice kept together
3. `exports/html/eco114_a3_markets_units_6_7_8_10_v2_unit_tabs.html` - recommended Markets v2 unit-first hub for Units 6, 7, 8, and 10 with each unit's theory, graphs, formulas, traps, templates and practice kept together
4. `exports/html/eco114_a3_exam_warroom.html` - final revision, past-paper strategy, traps, and mock practice

Legacy and beta files:

- `exports/html/eco114_a3_markets_units_6_7_8_10.html` - original global-bank Markets Hub. It remains preserved as a legacy version.
- `exports/html/eco114_a3_foundations_units_1_to_5.html` - original global-bank Foundations Hub. It remains preserved as a legacy version.

## Included Units

A3 scope currently includes Units 1, 2, 3, 4, 5, 6, 7, 8, and 10.

## Excluded Unit

Unit 9 is excluded for now because it is not shown in the 2026 ECO114 work programme. Add it later only if the lecturer confirms it is examinable.

## How To Open The HTML Files

Open the files directly in a browser from `exports/html/`, or start with:

`exports/html/eco114_a3_index.html`

The scaffold is designed to work in local file mode without external dependencies.

## Source Handling Note

Raw university material, slides, past papers, memos, textbook extracts, and lecturer-owned content should not be redistributed if repository visibility changes or sharing policies change. Generated study outputs should cite and summarise sources without exposing restricted materials unnecessarily.
